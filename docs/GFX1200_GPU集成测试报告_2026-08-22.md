## 3. MES v2 多 Workgroup 挂起问题

### 3.1 现象

| Workgroup 数 | 结果 |
|---------------|------|
| 1 | ✅ 正常 |
| 2 | ⚠️ 偶发挂起 |
| 4+ | ❌ 100% GPU hang |

挂起时 GPU 无响应，需要 `echo 0 > /sys/class/drm/card1/device/power_dpm_force_performance_level` 或系统重启恢复。

### 3.2 根因分析

**结论: GFX1200 MES v2 固件调度死锁**

证据链:
1. **libkfd kfdtest 同样复现**: 独立的 KFD 测试套件在 GFX1200 上同样多-WG 挂起
2. **geisYaO 博文确认**: 原作者在博文（已归档于 `docs/blog_geisYaO_全部博文_2026-08-22.md`）中描述了相同的挂起现象
3. **tinygrad AM 驱动绕过**: tinygrad 使用 SDMA 队列直接提交（绕过 MEC scheduler）而非多 compute WG
4. **GFX1100 正常**: 同一代码在 GFX1100 上 8-WG 并发无问题

**技术细节**:
- GFX1200 的 MES v2 固件 (`gc_12_0_0_mes.bin.zst`) 中 MEC (Micro Engine Compute) 调度器在 ≥4 WG 时出现死锁
- 与 KFD 队列类型无关（compute/hsa 队列均受影响）
- 与 CWSR (Context Save/Restore) 配置无关

### 3.3 解决方案: K6 持久内核

采用 **2 WG 持久内核 + 原子工作认领** 模式绕过:

```
┌───────────────────────────────────────────┐
│  Grid: 2 workgroups                       │
│  ┌─────────────────┐ ┌─────────────────┐  │
│  │ WG0: scc=1      │ │ WG1: scc=1      │  │
│  │ atomicAdd(&ctr,  │ │ atomicAdd(&ctr,  │  │
│  │   wave_size)     │ │   wave_size)     │  │
│  │ my_tile = old    │ │ my_tile = old    │  │
│  │ while more_work: │ │ while more_work: │  │
│  │   compute_tile() │ │   compute_tile() │  │
│  └─────────────────┘ └─────────────────┘  │
│  共享计数器: &tile_counter (GDS/GWS)      │
└───────────────────────────────────────────┘
```

**关键实现**:
- `s_barrier_signal -1` / `s_barrier_wait -1` 替代不支持的 `s_barrier`
- `readfirstlane` 进行 wave 级工作认领
- `atomicAdd` 全局计数器分配 tile
- 双缓冲 LDS 预取下一 tile

## 5. GFX1200 ISA 编码变更摘要

从 GFX1100 (RDNA3) 到 GFX1200 (RDNA4) 的关键编码差异:

| 项目 | GFX1100 | GFX1200 |
|------|---------|---------|
| SMEM word0 | `0xF4000000 \| (size<<14) \| (dst<<8) \| (base/2)` | `0xF4000000 \| (size<<12) \| (dst<<6) \| (base/2)` |
| VGLOBAL 格式 | 2-dword (64-bit) | 3-dword (96-bit) |
| VGLOBAL offset | word0 bits[41:32] | word2 bits[27:8] (`offset<<8`) |
| VGLOBAL vsrc store | N/A | `(vsrc/2) \| ((vsrc&1)<<23)` |
| Barrier | `s_barrier` (伪指令) | `s_barrier_signal -1` + `s_barrier_wait -1` |
| e_flags | `0x041` | `0x048` |
| EXEC guard | `s_setexeclo_b32` | `s_mov_b32 exec_lo, -1` |
| MEM_ORDERED | RSRC1 bit30=0 | RSRC1 bit30=1 (bare-metal KFD) |
| Waitcnt | 单指令 `s_waitcnt` | SOPP split: `s_wait_loadcnt/storecnt/dscnt/kmcnt` |
